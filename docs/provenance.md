# Source provenance

The terminal codec and its existing unit tests were extracted from
[LIghtJUNction/ztty](https://github.com/LIghtJUNction/ztty), directory
`crates/zinput`, at commit
`155fea51aa138b0503ea1d80be4252aacb2c61a7`. The MIT license and author are retained.

Version 0.1.3 adds bounded input-method state, Linux evdev byte decoding and the
optional typed engine interface. It preserves the prior public terminal encoding
APIs. The engine ABI is generated by zplugin; native library access uses zsys
through that dependency.

The native event fixture uses the installed Linux UAPI headers to establish the
host record layout. Its protocol behavior follows the
[Linux input event documentation](https://www.kernel.org/doc/html/latest/input/event-codes.html).
The reference engine contains two illustrative Chinese candidates and accepts
literal UTF-8; it does not embed an external language dictionary.
